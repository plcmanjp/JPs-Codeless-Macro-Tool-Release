# v1.6.0

출시일: 2026-07-28

## 새로운 기능

- **Chrome 텍스트 입력 모드**: Chrome을 앞으로 가져오지 않고, 사용자가 선택한 Chrome 창 안에서 클릭 지점으로 확인된 편집 요소 또는 유일하게 안전하게 식별되는 편집 요소의 전체 값을 바꿀 수 있습니다. 대상 요소를 안전하게 확인할 수 없으면 다른 곳에 입력하지 않고 중단합니다.
  키 스텝은 기존 호환 입력 경로에 따라 Chrome을 활성화한 뒤 실행하며, 이 모드에서 마우스 스텝은 지원하지 않습니다.

- **보조좌표 즉시 추가**: 마우스 스텝을 추가하거나 편집할 때 보조좌표 단축키(기본값 F3)를 누르면 현재 마우스 커서 위치가 좌표 테이블의 새 행으로 바로 추가됩니다.

## 개선 사항

- **동적 창 제목 대상 유지**: Chrome처럼 페이지 이동에 따라 창 제목이 바뀌어도 같은 실행 파일·창 클래스·실행 중인 창임이 확인되면 대상을 유지합니다. 후보가 모호하거나 창이 바뀌면 다른 곳에 입력하지 않고 안전하게 중단합니다.
- **백그라운드 입력 안전 중단**: Chrome 텍스트 입력 모드에 마우스 스텝이 포함되거나 편집 요소를 확인할 수 없는 경우 사용 방법을 안내한 뒤 실행을 중단합니다.

## 버그 수정

- **샘플 스텝 언어 불일치 수정**: 영어 화면에서 새 샘플의 주석과 구구단 제목·결과 변수가 한국어로 생성되던 문제를 수정했습니다. 한국어 화면은 기존 형식을 유지합니다.

> 기존에 저장된 매크로의 주석이나 변수 이름은 자동으로 변경하지 않습니다. 샘플 언어 변경은 업데이트 후 새로 추가하는 샘플부터 적용됩니다.
