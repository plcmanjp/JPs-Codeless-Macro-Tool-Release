# v1.6.0

Release date: 2026-07-28

## New features

- **Chrome Text input mode**: Without bringing Chrome to the foreground, the app can replace the full value of an editable element in the Chrome window selected by the user when it is confirmed at the click point or is the sole safely identifiable editable candidate. If the element cannot be verified safely, playback stops instead of sending input elsewhere.
  Key steps activate Chrome through the existing compatibility input path before they run, and mouse steps are not supported in this mode.

- **Instant auxiliary-coordinate insertion**: While adding or editing a mouse step, pressing the auxiliary-coordinate shortcut (F3 by default) appends the current mouse cursor position as a new row in the coordinate table.

## Improvements

- **Dynamic window-title target retention**: Targets such as Chrome remain bound after navigation changes the window title when the same executable, window class, and live window can be verified. Ambiguous or replaced windows stop safely instead of receiving input elsewhere.
- **Safe stop for background input**: If a Chrome Text macro contains a mouse step or the editable element cannot be verified, the app shows guidance and stops playback.

## Bug fixes

- **Fixed sample-step language mismatch**: In the English interface, newly inserted sample comments and multiplication-table headings and result variables were incorrectly created in Korean. The existing Korean format remains unchanged in Korean.

> Existing comments and variable names in saved macros are not changed automatically. The sample-language change applies to samples inserted after updating.
