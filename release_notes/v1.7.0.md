# v1.7.0

출시일: 2026-07-29

## 새로운 기능

- **실행 전 매크로 검사**: 재생을 시작하기 전에 반복·조건·포인터 구조, 누락된 이미지, 잘못된 대상 창 설정과 지원하지 않는 Chrome 입력 조합을 확인합니다. 문제가 있으면 실제 키보드·마우스 입력을 시작하지 않고 오류 위치와 해결 방법을 안내합니다.
- **직전 정상본 자동 보관**: 기존 프로젝트를 덮어쓸 때 현재 `script.json`을 `script.json.prev`로 한 세대 보관합니다. 프로젝트 파일이 손상되어 열리지 않으면 직전 정상본으로 복구할 수 있습니다.

## 개선 사항

- **실행 폭주 방지**: 최대 실행 스텝, 반복 횟수, 포인터 호출 깊이와 전체 실행 시간에 안전 한도를 적용합니다. 한도 중단은 일반 오류나 사용자의 중지와 구분해 기록합니다.
- **이미지·OCR 결과 추적**: 이미지 검색과 OCR 결과에 성공 여부, 좌표, 검색 영역과 원본 스텝 위치를 함께 보존합니다. 기존 매크로의 마지막 검색 좌표 사용 방식은 그대로 유지됩니다.
- **실행 기록 개인정보 보호**: 새 내부 실행 감사 기록에는 텍스트 입력값, 비밀번호, 토큰과 인증 정보를 남기지 않거나 마스킹합니다.

> 프로젝트 저장 형식은 계속 버전 1을 사용합니다. 기존 프로젝트는 별도 변환 없이 열고 저장할 수 있으며, AI·셸·자율 실행 기능은 이번 버전에 포함되지 않습니다.
