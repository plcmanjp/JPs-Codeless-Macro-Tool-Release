# v1.7.0

Release date: 2026-07-29

## New features

- **Preflight macro validation**: Before playback starts, the app checks loop, condition, and pointer structure, missing images, invalid target-window settings, and unsupported Chrome input combinations. Blocking problems are reported with their source step and corrective guidance before any keyboard or mouse input is sent.
- **Automatic previous-good snapshot**: Before an existing project is overwritten, its current `script.json` is kept as a single-generation `script.json.prev` snapshot. If the project can no longer be opened, the app can restore that previous copy.

## Improvements

- **Runaway execution protection**: Safety limits now cover executed steps, loop iterations, pointer-call depth, and total playback time. A limit stop is tracked separately from a normal error or a user-requested stop.
- **Image and OCR result tracking**: Image-search and OCR results retain success state, coordinates, search region, and source-step location while preserving the existing last-result coordinate behavior for saved macros.
- **Privacy-safe execution audit**: The new internal execution audit omits or masks typed text, passwords, tokens, and credentials.

> The project file format remains version 1. Existing projects open and save without a format conversion. AI, shell, and autonomous execution features are not included in this release.
